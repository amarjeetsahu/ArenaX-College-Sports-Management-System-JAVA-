# ⚡ ArenaX — College Sports Tournament Management System

> Your Campus. Your Teams. Your Game.

ArenaX is a Java-based College Sports Tournament Management System designed to manage players, teams, coaches, tournaments, venues, matches, and scores through a graphical user interface.

## ✨ Features

- **Player Management** — Manage player records.
- **Team Management** — Organize and manage teams.
- **Coach Management** — Maintain coach information.
- **Tournament Management** — Manage tournament details.
- **Venue Management** — Maintain venue records.
- **Match Management** — Manage scheduled matches.
- **Score Management** — Maintain match scores.
- **Interactive Dashboard** — View an overview of the system.
- **Match Schedule** — View scheduled matches.
- **Match Results** — View match results and scores.
- **Search Functionality** — Search records within supported modules.
- **Graphical User Interface** — Navigate through a custom Java Swing interface.

## 🛠️ Tech Stack

- Java
- Java Swing
- JDBC
- MySQL
- Maven
- Git and GitHub

## 📋 Prerequisites

Before running ArenaX, make sure you have:

- Java JDK installed
- Apache Maven installed
- MySQL Server installed and running
- A MySQL database named `sportsdb`
